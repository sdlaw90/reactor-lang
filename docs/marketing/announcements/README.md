# Release announcements

The postable copy for every release, versioned alongside the art it ships with.

**This folder is canonical.** The announcement used to live only in project knowledge, where
`deploy <tier>-pre-release` could not see it — so "the post exists" was a printed reminder
rather than a check. Now it is asserted like the art: an X.Y release does not proceed without
`v<version>.md` here.

What is NOT gated: whether it has actually been **posted**. That is a human action with no
signal the repo can read, and pretending otherwise would be a check that cannot fail.

Shape and accuracy rules: `claude/squirrelingo_release_announcement_rule.md`.
Art that ships with it: `../social/` and `../covers/`.
