## What was deliberately NOT claimed

That the explanations are in French. Only the pronunciation ones were — same as Portuguese.
Help/About were reworded that release to stop overclaiming, and the post matched.

**That caveat expired with v3.4**, which backfilled pt/fr explanations to 100%. See
`v3.4.0.md`, and the accuracy section of
`claude/squirrelingo_release_announcement_rule.md`, which now records both retired caveats so
a later release doesn't re-apply one.
